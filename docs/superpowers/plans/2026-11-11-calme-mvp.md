# Calme MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serveur local qui relève Gmail et fait trier les mails par Claude Code, interface web/PWA conforme aux maquettes, client de bureau Electron, notifications bureau + iPhone.

**Architecture:** `server/` (Node 24 TS natif, Hono, node:sqlite, Gmail API, `claude -p`) sur 127.0.0.1:4747 ; `web/` (Vite+React) servie par le serveur ; `desktop/` (Electron) client léger. Accès iPhone via `tailscale serve`.

**Tech Stack:** Node 24, pnpm workspaces, TypeScript, Hono + @hono/node-server, node:sqlite, @googleapis/gmail, google-auth-library, web-push, Vitest, Vite, React 18, Electron, electron-builder.

**Spec:** `docs/superpowers/specs/2026-11-11-calme-design.md`

## Global Constraints

- Serveur : écoute `127.0.0.1` port `4747` (env `CALME_PORT`), données dans `~/.calme/` (env `CALME_HOME`).
- Toute route `/api/*` exige `Authorization: Bearer <pairingToken>` ; sinon 401.
- Claude : `claude -p --tools "" --strict-mcp-config --setting-sources "" --no-session-persistence --output-format json --model <CALME_MODEL|sonnet> --json-schema <schema> --system-prompt <system>` ; prompt sur stdin ; lire `structured_output`.
- Aucun envoi / corbeille / désabonnement sans requête explicite de l'UI. Jamais de suppression définitive.
- Relève : `in:inbox newer_than:30d`, max 200 ; texte IA tronqué à 4000 caractères ; triage par lots de 10.
- PJ : 20 Mo max total → 413.
- Catégories : `reply | read | news | trash`. Libellés FR : À répondre, À lire, Newsletters, À supprimer.
- Thème : tokens des maquettes (sombre défaut `#0D0E11`, accent `#C8F03C`, chaud `#FF7A2F` ; clair `#EAE9E4`), polices Instrument Serif / Geist / Geist Mono.
- Mails affichés en texte uniquement, jamais `dangerouslySetInnerHTML`.

## Review Focus

1. Mail HTML seul, quoted-printable, charset iso-8859-1 → texte lisible (Task 2).
2. Claude renvoie un JSON incomplet, des ids inconnus, ou échoue → mails restent « non analysés », pas de crash, retentés à la relève suivante (Task 4).
3. Jeton absent/faux → 401 ; callback OAuth hors loopback → 403 (Task 5).
4. PJ au nom accentué → nom encodé correctement ; total > 20 Mo → 413 (Tasks 2, 5).
5. Jeton Google révoqué → `/api/state` renvoie `gmail: "disconnected"` et l'UI propose de reconnecter, la relève ne boucle pas (Tasks 3, 5).

### Task 5: Actions, notifications et API
